# us_declaration

세계사 주제28 「독립 선언문」 분석 + 한계 파악 웹앱 (3학년, 교과서 142~143쪽).

- 파일: `index.html` / `style.css` / `data.js`(콘텐츠) / `app.js`(로직). 빌드 단계 없음.
- 미리보기: `?preview=1` (저장 없음). 자동채움: `?sid=30512&name=이름`.
- 흐름: ① 찾기(3화면) → ② 쓰기(3화면) → ③ 읽기(입장 고르기 + 입장당 2화면) → ④ 마무리(2화면). 화면당 정보량을 줄이려고 나눴고, 쓰기 분량은 찾기 단어·구절, 대표 글 2문장, 입장 이유 1문장 기준이다. 조항 카드에는 질문과 위치 단서만 있고 답은 학생이 쓴다.
- 저장 JSON(`choicesJson`)에 `find`(조항 4개 답)가 추가됐다. 기존 필드는 그대로이고 시트 구조 변경은 없다.
- 포털 커리큘럼 관리에 activity id 하나 등록: `28차시_독립선언문_글쓰기` (`app.js`의 `CONFIG.GAME_NAME`). 저장은 마무리에서 한 번만 일어난다.
- 저장은 기존 기본 제출 경로(`gameName`/`choicesJson`)를 쓰며 백엔드 변경 없음.
